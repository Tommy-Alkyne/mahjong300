# 何切300问 · 单题网页版

## 阅读

双击 `dist/index.html`。主区域每次只显示一道题及折叠的中文答案。顶部“目录与资料”打开侧栏，里面包含跳题、目录、原书对照、讲解专栏、术语及使用说明。底部切换上一题、下一题或随机题。

支持键盘左右方向键切题；目录打开时不会触发切题。切换题目后答案重新收起。阅读位置和选牌记录只保存在当前浏览器，不需要账号或数据库。

## 部署到服务器

将 **dist 文件夹里面的全部内容** 上传到站点的静态文件目录，入口是 `index.html`。`index.html`、`reader/` 与 `images/` 必须放在同一级。

无需安装Node.js，无需编译，无需数据库或后端接口。适用于常规静态网站托管；也可放在已有域名的子目录，例如 `/mahjong/`。所有资源使用相对路径，题号使用 `#q001` 至 `#q300`，不需要为题目配置URL重写。

部署后的示例入口：`https://你的域名/mahjong/index.html#q001`。浏览器刷新、复制链接和前进后退均保留题号。更换域名或浏览器不会同步本地做题记录。

请按静态文件正常提供 `.html`、`.css`、`.js`、`.png` 和 `.webp`。验证部署时依次打开第1题、第42题（副露）、第132题（暗杠）和第300题，并展开答案与菜单中的专栏图解。

## 维护

- `dist/index.html`：页面结构。
- `dist/reader/reader.css`：样式。
- `dist/reader/reader.js`：切题、选牌、侧栏与折叠交互。
- `dist/reader/content.js`：300道题及全书阅读资料，数据与已完成的中文全书版本一致。
- `dist/images/`：题面、解析、图解与电子牌图，按需加载。

部署包与完整Markdown全书包分开提供。译文、题号、推荐答案和来源记录沿用全书版本。本次未连接服务器或发布站点。
